# V1.1 State Machine

V1.0 是规则层，V1.1 增加执行层：

- 非法状态转换直接失败
- DONE 必须有 PASS evidence 覆盖所有 acceptance criteria
- WIP 自动限制
- Release 只有通过验证并存在 Git tag 才能 RELEASED
- 状态变更进入 events.yaml
- Scope checker 用当前任务 allowed_paths 对 Git 工作区做范围检查

## 关键边界

机器可以验证“记录是否自洽”，但无法完美理解产品意图。因此语义判断仍需要人或高层 AI 审核。目标不是消灭变化，而是让变化显式化、可追踪、可回退。
